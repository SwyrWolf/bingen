## Core x86-64 Instructions

| Instruction | What it does |
| --- | --- |
| `mov` | Copies data from the source to the destination. |
| `movzx` | Copies a smaller unsigned value into a larger register and fills the upper bits with zeros. |
| `movsx` | Copies a smaller signed value into a larger register and fills the upper bits with the source sign bit. |
| `movsxd` | Sign-extends a 32-bit signed value to a 64-bit register. |
| `lea` | Computes an address or arithmetic expression without reading memory. |
| `xchg` | Exchanges the values of two operands. |
| `push` | Places a value on the stack. |
| `pop` | Removes a value from the stack. |
| `add` | Adds the source value to the destination. |
| `sub` | Subtracts the source value from the destination. |
| `mul` | Multiplies an unsigned integers; Must be store in the `a` register, expands to the `d` register. |
| `imul` | Multiplies signed integers; unlike `mul`, it also supports two- and three-operand forms. |
| `inc` | Increases a value by one. |
| `dec` | Decreases a value by one. |
| `cmp` | Compares two values and updates the CPU flags. |
| `test` | Performs a bitwise AND and updates flags without saving the result. |
| `and` | Performs a bitwise AND. |
| `or` | Performs a bitwise OR. |
| `xor` | Performs a bitwise exclusive OR. |
| `jmp` | Jumps to another instruction. |
| `je` / `jz` | Jumps when values are equal or the result is zero. |
| `jne` / `jnz` | Jumps when values are unequal or the result is not zero. |
| `call` | Calls a function and saves the return address. |
| `ret` | Returns from a function. |
| `nop` | Does nothing. |

### SIMD / floating-point registers

| Register | Size | Common use |
| --- | ---: | --- |
| `xmm0` | 128 bits | First floating-point return value / first FP argument |
| `xmm1` | 128 bits | FP temporary / second FP arg |
| `xmm2` | 128 bits | FP temporary / third FP arg |
| `xmm3` | 128 bits | FP temporary / fourth FP arg |
| `xmm4`-`xmm15` | 128 bits | Additional SIMD / FP registers |
| `ymm0` | 256 bits | 256-bit vector extension of `xmm0` |
| `zmm0` | 512 bits | 512-bit SIMD register, used with AVX-512 |

On Windows x64, `float` and `double` return values commonly go in `xmm0`, while integer return values still go in `eax`/`rax`.

> Registers have sizing aliases for 32, 16, and 8 bits.  
`rax` 64 bit register can be `eax` (32), `ax` (16), `al` (8 : low byte of `ax`),
`ah` (8 high byte of `ax`)  
The same sizing applies to `rbx`/`rcx`/`rdx`  
While `rsi`/`rdi`/`rsp`/`rbp` use `sil`/`dil`/`spl`/`bpl` and `r8`–`r15` use `r8d`/`r8w`/`r8b`, etc.
